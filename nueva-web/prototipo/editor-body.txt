<h1>Gestor de contenidos</h1>
<p>Edita los textos de Inicio, Cine y Servicios, o crea páginas en español e inglés. Los cambios se preparan en tu navegador y se publican desde la cuenta de GitHub con permisos sobre la web.</p>
<ol>
  <li>Edita los campos y descarga el archivo actualizado.</li>
  <li>Abre la carpeta de contenidos en GitHub y usa «Add file → Upload files» para sustituir <strong>site-content.json</strong> por el archivo descargado.</li>
  <li>Confirma el cambio en GitHub. La web se actualizará cuando termine su despliegue.</li>
</ol>
<p>Revisa los cambios antes de publicarlos. Este editor no pide ni almacena contraseñas o claves de GitHub.</p>
